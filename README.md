# 에듀파인 비서

전북 업무포털(K-에듀파인 · 4세대 나이스)의 반복 업무를 덜어 주는 교사용 PC 프로그램입니다. — 만든 사람 teacher.K

## 내려받기

**홈페이지: https://kang-t.github.io/edufine-assistant-release/** — 무엇을 하는 프로그램인지, 화면과 설치 방법을 볼 수 있습니다.

**사용 안내: https://kang-t.github.io/edufine-assistant-release/guide.html** — 설치, 백신이 막을 때, 기능별 사용법, 로컬 AI, 문제 해결.

**[최신 판 내려받기 →](https://github.com/Kang-T/edufine-assistant-release/releases/latest)**

위 페이지 아래쪽 **Assets** 에서 `EdufineAssistant_Setup_…zip` 을 누르세요.

## 설치

1. 받은 zip 파일을 **오른쪽 클릭 › 속성 › 맨 아래 「차단 해제」 체크 › 확인** (이렇게 하면 파란 「Windows의 PC 보호」 창이 뜨지 않습니다)
2. zip 을 풀고 `에듀파인비서_설치_….exe` 를 두 번 누르기
   - 파란 창이 뜨면 **[추가 정보] → [실행]** (서명 인증서를 사지 않은 무료 프로그램이라 뜨는 안내입니다)
3. **[설치] → [비서 켜기]** — 관리자 권한이 필요 없고, Chrome 이 깔려 있어야 합니다
4. 처음 켜면 학교 이름·근무 지역·연락처·**맡은 업무**를 한 번 여쭙니다
5. 인증서 창이 뜨면 비밀번호를 넣어 로그인합니다

## 하는 일

- 결재대기·공람대기 공문을 정해진 시각에 확인하고, 내 업무 공문에 ★·업무 배지·할 일 표시
- 결재대기 공문을 과제카드·공람과 함께 묶어 **문서처리**
- 나이스 **육아시간(하루·주 단위)·조퇴·병가·출장** 신청 창 채우기 — [승인요청]은 선생님이
- **지난 공문 찾기**(접수한 문서·공람완료), **매달 하는 기안**·품의 초안, 공람대기 정리
- 컴퓨터를 켜면 저절로 켜지고, 새 판은 「업데이트할까요?」로 묻습니다

## 지키는 것

- 인증서 비밀번호는 저장하지 않습니다. 결재올림·승인요청·결재요청은 늘 선생님이 누릅니다
- 공문 내용은 이 PC 밖으로 나가지 않습니다(AI 요약도 PC 안의 로컬 AI 만)
- 로그인 정보·설정·기록은 이 PC 의 선생님 폴더에만 둡니다

## 오류·의견·내 업무 흐름

비서 화면 맨 아래 **「💡 업무 흐름·오류·의견 보내기」** — 알려 주신 업무 흐름은 「업무 팩」으로 만들어 모든 선생님 비서에 넣어 드립니다.

이 저장소에는 설치 파일과 업무 팩만 있습니다.
